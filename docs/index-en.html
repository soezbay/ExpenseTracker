🧾 Expense Tracker

A Telegram bot that reads receipts from photos, evaluates them locally via OCR (Ollama), and answers questions about your expenses with an AI agent.

n8n Ollama Kotlin Telegram Bot Local LLMs
Code Repository ↗ View Demo
Deutsch · English

Features

📸 Receipt OCR

Send a photo → the Ollama vision model automatically extracts merchant, amounts, VAT, and items.

🤖 AI Agent

Answers natural-language questions: statistics, period comparisons, top merchants, categories.

🏷️ Categorization

Rule-based assignment to categories like Groceries, Transport, or Restaurant.

📊 Excel Export

/export [year] generates a complete .xlsx file of all receipts.

🔒 Local & Private

No cloud LLM – OCR and agent run entirely on self-hosted Ollama.

⚙️ Infrastructure as Code

The entire n8n workflow is created programmatically via a Kotlin client.

Architecture

Telegram Bot
    ↓
n8n Workflow (Trigger → OCR → Validation → Storage → AI Agent)
    ↓
Ollama (local LLM/Vision model)  →  OCR + AI Agent (tool calling)
    ↓
JSONL files (receipts_YYYY.jsonl) + images (bin/)

Quick Start

git clone https://github.com/soezbay/ExpenseTracker.git
cd ExpenseTracker
docker compose up -d
cd n8n-api-client
cp .env.example .env   # Add Telegram token & n8n API key
./gradlew runTelegram
