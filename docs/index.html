🧾 Expense Tracker

Ein Telegram-Bot, der Kassenbons per Foto liest, lokal per OCR (Ollama) auswertet und Fragen zu deinen Ausgaben mit einem AI Agent beantwortet.

Features

📸 Kassenbon-OCR

Foto senden → Ollama-Vision-Modell extrahiert Händler, Beträge, MwSt & Artikel automatisch.

🤖 AI Agent

Beantwortet natürliche Fragen: Statistiken, Zeitraumvergleiche, Top-Händler, Kategorien.

🏷️ Kategorisierung

Regelbasierte Zuordnung zu Kategorien wie Lebensmittel, Transport, Restaurant.

📊 Excel-Export

/export [Jahr] erzeugt eine vollständige .xlsx-Datei aller Belege.

🔒 Lokal & privat

Kein Cloud-LLM – OCR und Agent laufen komplett auf selbst-gehostetem Ollama.

⚙️ Infrastructure as Code

Der gesamte n8n-Workflow wird programmatisch über einen Kotlin-Client erzeugt.

Architektur

Telegram Bot
    ↓
n8n Workflow (Trigger → OCR → Validierung → Speichern → AI Agent)
    ↓
Ollama (lokales LLM/Vision-Modell)  →  OCR + AI Agent (Tool-Calling)
    ↓
JSONL-Dateien (receipts_YYYY.jsonl) + Bilder (bin/)

Schnellstart

git clone https://github.com/soezbay/ExpenseTracker.git
cd ExpenseTracker
docker compose up -d
cd n8n-api-client
cp .env.example .env   # Telegram-Token & n8n API-Key eintragen
./gradlew runTelegram
